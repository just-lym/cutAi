## Dockerfile (后端)

### GPU 版 (默认 - Windows/Linux + NVIDIA)

```dockerfile
FROM nvidia/cuda:12.2.0-runtime-ubuntu22.04

RUN apt-get update && apt-get install -y --no-install-recommends \
    python3.11 python3.11-venv python3-pip \
    ffmpeg \
    && rm -rf /var/lib/apt/lists/* \
    && ln -sf /usr/bin/python3.11 /usr/bin/python3 \
    && ln -sf /usr/bin/python3.11 /usr/bin/python

WORKDIR /app

COPY ../pyproject.toml .

RUN pip install --no-cache-dir .

COPY app/ app/

EXPOSE 8000

CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```
### CPU 版 (Dockerfile.cpu - macOS/CI)
```dockerfile
FROM python:3.11-slim

RUN apt-get update && apt-get install -y --no-install-recommends \
    ffmpeg \
    && rm -rf /var/lib/apt/lists/*

WORKDIR /app

COPY pyproject.toml .

RUN pip install --no-cache-dir .

COPY app/ app/

EXPOSE 8000

CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```
Mac 使用时修改 docker-compose.yml: `build: {context: ./backend, dockerfile: Dockerfile.cpu}`, 
并去掉 `deploy.resources` 和设置 `FFMPEG_HWACCEL: ""`。

## Dockerfile (前端)

```dockerfile
FROM node:20-alpine AS build
WORKDIR /app
COPY package.json package-lock.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY nginx.conf /etc/nginx/conf.d/default.conf
COPY --from=build /app/dist /usr/share/nginx/html
EXPOSE 80
```
nginx.conf (前端生产)
```nginx
server {
  listen 80;
  root /usr/share/nginx/html;
  index index.html;

  location / {
    try_files $uri $uri/ /index.html;
  }

  location /api/ {
    proxy_pass http://backend:8000;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_buffering off;
  }

  location /ws/ {
    proxy_pass http://backend:8000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
  }
}
```

### Windows 注意事项

- Redis: Windows 官方不支持 Redis，推荐用 Docker 跑 Redis 或用 Memurai (兼容替代)
- FFmpeg: 确保将 `ffmpeg` 在 PATH 中，安装后执行 `ffmpeg -version` 验证
- CUDA 加速: 如有 NVIDIA GPU，设置 `FFMPEG_HWACCEL=cuda` 即可启用硬件编码
- 路径: `DATA_ROOT` 改为 Windows 路径，如 `C:\aicut-data`
- 推荐: 使用 WSL2 或 Docker Desktop，避免路径和权限问题

## Docker 一键启动

### Windows (推荐 - GPU 加速)

双击 `start.bat` 即可，脚本自动完成：
1. 检测 Docker + NVIDIA GPU
2. 首次运行提示输入百炼 API Key - 保存 `.env`
3. 构建镜像 -> 启动全部服务 -> 初始化数据库
4. 自动打开浏览器

停止: 双击 `stop.bat`

### 手动启动 (任意平台)

```bash
# 创建 .env
echo "DASHSCOPE_API_KEY=sk-your-key-here" > .env

# 构建并启动
docker compose up -d

# 查看日志
docker compose logs -f backend

# 初始化数据库 (首次)
docker compose exec backend alembic upgrade head
```
### 脚本文件

| 文件 | 平台 | 说明 |
|------|------|------|
| start.bat | Windows | 一键启动 (检测 GPU + 部署 + 打开浏览器) |
| stop.bat | Windows | 一键停止 |

## FFmpeg 硬件加速

代码中自动适配 GPU/CPU:
- `FFMPEG_HWACCEL=cuda` -> 使用 h264_nvenc 硬件编码 (5-10x 加速)
- `FFMPEG_HWACCEL=` (空) -> fallback 到 libx264 软编码

影响的工具函数:
- `media_tools.generate_proxy()` -> 代理视频生成
- `render_tools.render_preview()` -> 预览渲染
- `render_tools.render_export()` -> 最终导出

## 生产部署注意事项

- 前端: nginx 已配置 SPA fallback + API/WS 反向代理
- 后端: 通过 `FFMPEG_HWACCEL=cuda` 开启 GPU 编码 (需 NVIDIA Container Toolkit)
- Windows: 需 Docker Desktop + WSL2 后端 + NVIDIA Container Toolkit
- Redis 用于 arq 任务队列 + WebSocket pub/sub (单机足够)
- PostgreSQL 数据持久化到 Docker volume `pgdata`
- 媒体文件持久化到 Docker volume `aicut_data` (映射 /data/aicut)
- 日志: uvicorn 默认 stdout, Docker 日志驱动收集
