# 模块 10: 执行器与资产流水线

## Timeline Executor (services/executor.py)

将已批准的 EditPlan 操作应用到当前 TimelineVersion，生成新版本。

### 接口

```python
async def execute_edit_plan(
    db: AsyncSession,
    project_id: UUID,
    operations: List[dict],
    created_by: str = "agent"
) -> TimelineVersion
```
## 支持的操作类型

| type | 必填字段 | 行为 |
|---|---|---|
| DELETE_RANGE | start_ms, end_ms | 从 clips 中删除该区间的片段 |
| SET_VOLUME | start_ms, end_ms, volume | 对区间内 clips 设置音量 (0~2.0) |
| INSERT_BROLL_OVERLAY | asset_id, position_ms, duration_ms | 在 B-roll 轨道添加 overlay clip |
| UPDATE_SUBTITLE | cue_id, text?, start_ms?, end_ms? | 更新字幕 cue 记录字段 |
| FADE_IN | start_ms, duration_ms | 在指定位置添加 fade-in 效果 |
| FADE_OUT | start_ms, duration_ms | 在指定位置添加 fade-out 效果 |

## 错误处理

- `ExecutionError` 异常 -> 操作不会执行
- 整体原子性：任意操作失败 -> 全部回滚，不创建新版本
- 调用方 (approve endpoint) 捕获 -> 返回 500 + error detail

## 集成点

approve endpoint 流程：
1. 收集 approved_indices 对应的 operations
2. 调用 `execute_edit_plan(db, project_id, ops)`
3. 成功 -> 更新 plan status，broadcast `timeline_updated` WS event
4. 失败 -> 返回 500, plan 状态不变

## Asset Processing Pipeline (jobs/pipeline.py)

上传后自动触发的全链路处理流水线，以 arq 异步任务运行。

### 触发方式

```python
# assets.py upload/import endpoint
await pool.enqueue_job("task_process_asset", str(asset.id), str(project_id))
```
### 流水线步骤

probe -> proxy -> thumbnails -> audio -> asr -> embedding

| 步骤 | 说明 | 适用类型 |
|---|---|---|
| probe | ffprobe 获取元数据 (duration, width, height, fps) | 全部 |
| proxy | 生成 720p 缩略代理文件 | VIDEO |
| thumbnails | 提取视频缩略图序列 | VIDEO |
| audio | 提取 WAV 音轨 | VIDEO |
| asr | DashScope Paraformer-v2 语音识别 -> SubtitleCue | VIDEO, AUDIO |
| embedding | text-embedding-v3 向量化 -> Chroma 索引 | 全部 |

### 状态追踪

Asset 模型字段：
- processing_status: PENDING -> PROCESSING -> COMPLETED / FAILED
- processing_step: 当前步骤名 (probe/proxy/.../embedding), 完成后 null

### WebSocket 进度广播

每步完成后广播 'job_progress' 事件：

```json
{
  "type": "job_progress",
  "data": {
    "asset_id": "...",
    "step": "asr",
    "current": 4,
    "total": 6,
    "progress": 0.66,
    "error": null
  }
}
```
### ASR 子流程
1. [] Paraformer-v2 异步转录任务
2. [] 轮询 (最多 60 次 = 5min)
3. 成功 -> 解析 sentences -> 创建 SubtitleCue 记录
4. 自动创建/复用 SUBTITLE 轨道

### 容错
- 各步骤独立 try/catch, 非致命步骤 (embedding) 失败不影响整体
- 失败 -> asset.processing_status = FAILED, 广播 error 事件
- 前端通过 query invalidation 获取最终状态

## WebSocket 连接管理 (ws/events.py)

class ConnectionManager:
    async def connect(project_id, websocket) -> None
    async def disconnect(project_id, websocket) -> None
    async def broadcast(project_id, event_type, data) -> None

manager = ConnectionManager() # 模块级单例

### 事件类型
| event_type | 触发时机 | data |
|---|---|---|
| job_progress | 流水线各步骤开始时 | asset_id, step, progress |
| timeline_updated | Executor 创建新版本后 | version, timeline_version_id |

### 前端消费 (Editor.tsx)

```typescript
useWebSocket(projectId, (event) => {
  if (event.type === 'timeline_updated') {
    queryClient.invalidateQueries({ queryKey: [] })
  } else if (event.type === 'job_progress') {
    queryClient.invalidateQueries({ queryKey: [] })
  }
})
```
## 前端进度 UI (AssetPanel)
处理中的素材显示 6 段进度条，按步骤着色：
- 已完成步骤: green
- 当前步骤: yellow + animate-pulse
- 未开始步骤: gray
通过 `asset.processing_step` 字段判断进度位置。
