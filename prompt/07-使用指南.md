# 模块 7: 使用指南 - 如何用本提示词生成项目

## 推荐生成顺序

1. **基础设施层**: 先生成 pyproject.toml, config.py, database.py, main.py
2. **数据库层**: 生成所有 models/ 下的文件，然后初始化 alembic
3. **工具层**: 生成 tools/ 目录 (纯逻辑，无外部依赖)
4. **云 API 层**: 生成 cloud_api/ 目录
5. **Provider 层**: 生成 providers/ 目录
6. **Agent 系统**: 生成 agents/ 目录 (依赖 tools + cloud_api)
7. **API 路由层**: 生成 api/ 目录
8. **任务队列**: 生成 jobs/worker.py
9. **WebSocket**: 生成 ws/events.py
10. **前端基础**: package.json, vite.config.ts, tailwind, tsconfig, index.html
11. **前端核心**: main.tsx, App.tsx, api/client.ts, stores/editor.ts, hooks/
12. **前端页面**: pages/ + components/
13. **Demo 组件**: components/demo/ (可选，用于无后端演示)
14. **部署文件**: Dockerfile (前后端) + docker-compose.yml + nginx.conf

## 逐模块提示词使用方法

每个模块文件可以单独作为 prompt 投喂给 AI，格式如下：
```
请根据以下设计文档，生成对应的代码文件。严格遵循文档中的：

类名/函数名/变量名

依赖版本

数据结构与类型定义

业务逻辑和算法

[粘贴对应模块的 .md 文件内容]
```



## 环境准备清单

### 必须条件
- NVIDIA GPU (GTX 1660+ / RTX 系列，支持 NVENC 编码)
- Docker + Docker Compose (GPU 支持: nvidia-container-toolkit)
- 阿里云 API Key (https://dashscope.console.aliyun.com/)

### 可选条件
- Runway API Key (B-roll 视频生成)
- Pika API Key (B-roll 生成)
- 可灵 API Key (B-roll 生成)

### 软件环境
- Python 3.11+
- Node.js 20+
- PostgreSQL 16
- Redis
- FFmpeg (需编译 含 NVENC 支持)

### 关键设计决策备忘

| 决策 | 选择 | 原因 |
|------|------|------|
| LLM Provider | 阿里 DashScope (Qwen) | 国内访问稳定，cost-effective |
| Agent 框架 | LangGraph | 支持条件路由、循环、状态管理 |
| ChatModel | 自定义 ChatDashScope 适配器 | LangChain 无官方 DashScope 集成 |
| 数据库 | PostgreSQL + asyncpg | JSONB 支持时间轴快照，async 性能好 |
| 任务队列 | arq (Go Celery) | 轻量，async-native，单进程 |
| 前端状态 | Zustand + 轻量 | TypeScript 友好、无 boilerplate |
| 时间轴组件 | react-timeline-editor | 开箱即用多轨编辑 |
| 视频播放 | @vidstack/react | 现代、可定制、性能好 |
| 画布叠加 | react-konva | 字幕/水印叠加层高效 2D 绘制 |
| 拖拽 | @dnd-kit | 可访问性好、模块化 |
| Agent sync/async | 双引擎 DB + ThreadPoolExecutor | LangChain tools 同步限制 |
| 时间轴存储 | 版本链 (JSONB 快照) | 简单可删，支持 undo |
| 编辑计划 | 结构化 JSON + 人工确认 | 避免 AI 直接修改数据 |
| GPU 渲染 | 异步队列 + 优先级 | 平衡成本 |
