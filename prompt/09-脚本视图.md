# 模块 9: 脚本视图 (ScriptView)

“编辑文字 = 编辑视频” 的交互范式。在编辑器下面板以 Tab 切换展示，与时间轴同域。

## 核心概念

ScriptView 将 ASR 产生的 SubtitleCue 以文本段落形式渲染，用户通过编辑文字间接操作时间轴：
- 修改文字 -> PUT 更新 SubtitleCue
- 删除文字 -> 生成 DELETE_RANGE 草稿操作
- 点击文字 -> Playhead 跳转到对应时间点
- 播放时 -> 当前 cue 高亮 + 自动滚动

## 数据流

1. 进入编辑器 -> useQuery GET /projects/{id}/subtitles -> setSubtitleCues
2. 播放时 playheadMs 变化 -> binary search 计算 currentCueId
3. currentCueId 变化 -> 对应 CueBlock 高亮 + scrollIntoView
4. 点击 CueBlock -> setPlayhead(cue.start_ms)
5. 编辑文字 -> debounce 300ms -> PUT /projects/{id}/subtitles/{cue_id}
6. 选中多个 cue (Shift+click) -> selectedCueIds -> 可批量删除
7. Delete 键 -> addDraftOp({type: "DELETE_RANGE", start_ms, end_ms})

## 播放同步 (Binary Search)

```typescript
// O(log n) 查找 playheadMs 落在哪个 cue 的 {start_ms, end_ms} 区间
function findCurrentCue(cues: SubtitleCue[], playheadMs: number): string | null {
  let lo = 0, hi = cues.length - 1
  while (lo <= hi) {
    const mid = (lo + hi) >> 1
    if (cues[mid].end_ms <= playheadMs) lo = mid + 1
    else if (cues[mid].start_ms > playheadMs) hi = mid - 1
    else return cues[mid].id
  }
  return null
}
```
## 自动滚动

- 使用 scrollIntoView({ behavior: "smooth", block: "center" })
- [防抖]：用户主动滚动后暂停自动滚动 3 秒
- 实现：监听 scroll 事件设置 userScrolledAt 时间戳，仅当距上次用户滚动 > 3s 时才触发

## 文本编辑

- contentEditable="plaintext-only" 禁止富文本粘贴
- onInput -> 300ms debounce -> api.subtitles.update(projectId, cueId, { text })
- 编辑时插入 undoStack (old text -> new text)

## 视觉状态

| 状态 | 样式 |
|---|---|
| 正常 | text-gray-200 |
| 当前播放 cue | bg-blue-900/40 border-l-2 border-blue-400 |
| 低置信度 (< 0.7) | bg-yellow-900/30 |
| 用户选中 | bg-purple-900/30 ring-1 ring-purple-500 |

## 搜索过滤

输入框实时过滤：仅显示 cue.text.includes(query) 的 CueBlock，其余隐藏。搜索结果中高亮匹配文字。
