# AI Cut - AI 多 Agent 智能视频剪辑平台 - 项目生成提示词

## # 项目定位
## # AI Cut - AI 多 Agent 智能视频剪辑平台
构建一个基于多 Agent 协作的 Web 视频剪辑平台。核心理念：**AI 分析决策，确定性工具执行，人工确认关键操作**。

*  本地 GPU 处理所有视频（FFmpeg + NVENC 硬件编码）
*  云端调用百川 4/2 模型 AI（Qwen LLM + Paraphraser ASR + Embedding）
*  外部视频生成（Runway / Pika / 可灵）生成 B-roll 素材
*  单机 Docker Compose 部署，无需 K8s

## # 架构总览

*  **前端** (React + TypeScript + Vite)
    *  HTTP REST + WebSocket
*  **后端** (FastAPI 单机部署)
    *  API 层：项目/素材/时间线/Agent/B-roll/渲染/调用
    *  Agent 层：Main Creative Agent (`create_agent` ReAct) + 专家 Agent 工具委托 + Review
    *  Tool 层：LangChain @tool 确定性工具
        *  本地：FFmpeg (probe/slice/encode/thumbnail/render)
        *  云端：Parafomer-ASR / Qwen LLM / text-embedding-v3
        *  外部：Runway / Pika / 可灵 (视频生成 Provider 适配层)
    *  任务队列：arq (基于 Redis 的轻量异步队列)
    *  WebSocket：实时事件广播 (进度、Agent 状态)
    *  数据层：PostgreSQL 16 + Redis 7 + 本地文件系统 + ChromaDB

## # 技术栈

*  **前端**: React, TypeScript, Vite, TailwindCSS, Zustand, TanStack Query | React 18, Vite 5
*  **前端组件**: react-timeline-editor, wavesurfer.js, @vidstack/react, react-konva, @dnd-kit, react-resizable-panels
*  **后端**: Python, FastAPI, SQLAlchemy 2.0 (async), Pydantic v2, pydantic-settings | Python 3.11+
*  **Agent**: LangGraph, langchain-core, dashscope SDK | langgraph>=0.2, langchain-core>=0.3
*  **语音转写**: Parafomer-ASR / Qwen LLM
*  **视频生成**: Runway Gen3a / Pika / 可灵 Klang (Provider 适配层)
*  **媒体处理**: FFmpeg + NVENC (h264_nvenc) 硬件编码
*  **任务队列**: arq (Redis-based) | arq>=0.26
*  **数据库**: PostgreSQL 16 (asyncpg + psycopg2-binary)
*  **向量检索**: ChromaDB (嵌入式模式) | chromadb>=0.3
*  **部署**: Docker Compose (单机, GPU passthrough)

## # 核心设计原则

*  **1. AI 分析，工具执行**：Agent 输出结构化 JSON 编排计划，确定性 Executor 执行时间轴操作
*  **2. 人工确认**：所有决策生成 Edit 预览，需人工确认后执行
*  **3. 高可用**：分布式处理机制（人工重试 + 断点续传），AI 推理生成 APK
*  **4. 成本可控**：API 费用实时追踪（月/日/项目），自动降级策略
*  **5. 环境自愈**：源码可复现，所有操作基于时间轴版本（版本可回滚）
*  **6. 单机 GPU 部署**：用户交互优先于后台协调，智能优先于输出（算力上限 1-2）
