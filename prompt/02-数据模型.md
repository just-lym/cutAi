# 模块 2: 数据模型 (SQLAlchemy ORM)

所有模型使用 SQLAlchemy 2.0 Mapped 注解风格，UUID 主键，PostgreSQL 方言 (JSONB, UUID)。

## Project 模型

```python
class ProjectStatus(str, enum.Enum):
    DRAFT = "DRAFT"
    PROCESSING = "PROCESSING"
    READY = "READY"
    EXPORTING = "EXPORTING"
    COMPLETED = "COMPLETED"
    FAILED = "FAILED"
    ARCHIVED = "ARCHIVED"

class Project(Base):
    __tablename__ = "projects"
    id: Mapped[uuid.UUID] = mapped_column(UUID(as_uuid=True), primary_key=True, default=uuid.uuid4)
    owner_id: Mapped[str] = mapped_column(String(64), index=True)
    name: Mapped[str] = mapped_column(String(255))
    width: Mapped[int] = mapped_column(Integer, default=1920)
    height: Mapped[int] = mapped_column(Integer, default=1080)
    frame_rate: Mapped[float] = mapped_column(Float, default=30.0)
    duration_ms: Mapped[int] = mapped_column(Integer, default=0)
    current_timeline_version: Mapped[int] = mapped_column(Integer, default=0)
    status: Mapped[ProjectStatus] = mapped_column(Enum(ProjectStatus), default=ProjectStatus.DRAFT)
    created_at: Mapped[datetime] = mapped_column(DateTime, server_default=func.now())
    updated_at: Mapped[datetime] = mapped_column(DateTime, server_default=func.now(), onupdate=func.now())
```
## Asset 模型
支持多种来源（用户上传、AI 生成、授权网络素材、系统生成），带处理状态跟踪：
```python
class AssetType(str, enum.Enum):
    VIDEO = "VIDEO"
    AUDIO = "AUDIO"
    IMAGE = "IMAGE"
    SUBTITLE = "SUBTITLE"
    TRANSCRIPT = "TRANSCRIPT"

class AssetSourceType(str, enum.Enum):
    USER_UPLOAD = "USER_UPLOAD"
    AI_GENERATED = "AI_GENERATED"
    LICENSED_WEB = "LICENSED_WEB"
    SYSTEM_GENERATED = "SYSTEM_GENERATED"
class ProcessingStatus(str, enum.Enum):
    PENDING = "PENDING"
    PROCESSING = "PROCESSING"
    COMPLETED = "COMPLETED"
    FAILED = "FAILED"

class Asset(Base):
    __tablename__ = "assets"
    id: Mapped[uuid.UUID] (UUID PK)
    project_id: Mapped[uuid.UUID] (FK -> projects.id, indexed)
    type: Mapped[AssetType]
    source_type: Mapped[AssetSourceType]
    original_name: Mapped[str] (String(512))
    file_path: Mapped[str] (String(1024))  # 相对于 data_root
    proxy_path: Mapped[str | None] (String(1024))
    mime_type: Mapped[str] (String(128))
    duration_ms: Mapped[int | None]
    width: Mapped[int | None]
    height: Mapped[int | None]
    frame_rate: Mapped[float | None]
    checksum: Mapped[str | None] (String(64))
    processing_status: Mapped[ProcessingStatus]
    metadata_: Mapped[dict | None] (JSONB, column name = "metadata")
    created_at: Mapped[datetime]
```

## Timeline 版本化模型

时间轴采用版本链设计，每次修改创建新版本，支持回溯：

```python
class TrackType(str, enum.Enum):
    VIDEO_MAIN = "VIDEO_MAIN"
    VIDEO_BROLL = "VIDEO_BROLL"
    IMAGE = "IMAGE"
    SUBTITLE = "SUBTITLE"
    AUDIO_ORIGINAL = "AUDIO_ORIGINAL"
    AUDIO_MUSIC = "AUDIO_MUSIC"
    AUDIO_SFX = "AUDIO_SFX"

class TimelineVersion(Base):
    __tablename__ = "timeline_versions"
    id: UUID PK
    project_id: UUID FK -> projects.id, indexed
    version: int
    parent_version_id: UUID nullable  # 版本链
    timeline_json: JSONB  # 完整时间轴快照
    change_summary: Text nullable
    created_by: String(64)  # "user" | "agent"
    created_at: DateTime

class Track(Base):
    __tablename__ = "tracks"
    id: UUID PK
    timeline_version_id: UUID FK -> timeline_versions.id, indexed
    type: TrackType
    name: String(128)
    order_index: int
    locked: bool (default=False)
    muted: bool (default=False)
    hidden: bool (default=False)

class Clip(Base):
    __tablename__ = "clips"
    id: UUID PK
    track_id: UUID FK -> tracks.id, indexed
    asset_id: UUID FK -> assets.id
    timeline_start_ms: int
    timeline_end_ms: int
    source_in_ms: int (default=0)
    source_out_ms: int
    speed: float (default=1.0)
    volume: float (default=1.0)
    transform: JSONB nullable  # 位置/缩放/旋转
    effects: JSONB nullable  # 滤镜/调色
    transition_in: JSONB nullable
    transition_out: JSONB nullable
```
