# 模块 8: 快捷键系统与撤销/重做

## 快捷键 Hook (useHotkeys)

全局键盘事件监听，挂载在 Editor 组件中。自动排除 input/textarea/contentEditable 焦点时的冲突。

### 快捷键映射

| 按键 | 功能 | 说明 |
|---|---|---|
| Space | 播放/暂停 | 标准 NLE |
| J | 后退 5s | - |
| K | 暂停 | - |
| L | 前进 5s | - |
| ← | playhead -100ms | Ctrl+= -1000ms |
| → | playhead +100ms | Ctrl+= +1000ms |
| Delete / Backspace | 删除选中 | 生成 DELETE_RANGE draft op |
| Ctrl+Z / Cmd+Z | 撤销 | - |
| Ctrl+Shift+Z / Cmd+Shift+Z | 重做 | - |
| Ctrl+S / Cmd+S | 保存 | commit draftOperations to timeline |

### 实现要点

```typescript
// hooks/useHotkeys.ts
- 监听 document keydown
- 匹配 event.code + ctrlKey/metaKey/shiftKey
- isEditable(): 排除 INPUT/TEXTAREA/SELECT 标签 或 el.isContentEditable
- 排除焦点在可编辑元素时的执行
```
## Undo/Redo 系统
基于前端操作栈的本 undo/redo，不依赖网络。Timeline version 作为远程 checkpoint 做同步。

### 数据结构
```typescript
interface UndoEntry {
  type: string           // 操作类型标识
  forward: object       // 正向操作参数
  backward: object      // 逆向操作参数 (undo 时执行)
  timestamp: number
}
```
### Store 拓展
```typescript
// store/editor.ts新增
undoStack: UndoEntry[]      // 最大 50 条
redoStack: UndoEntry[]
pushUndo(entry): void   // push -> undoStack, 清空 redoStack
undo(): void            // pop undoStack -> 执行 backward -> push to redoStack
redo(): void            // pop redoStack -> 执行 forward -> push to undoStack
```
### 可撤销操作

| 操作 | forward | backward |
|---|---|---|
| 删除 clip/cue | DELETE_RANGE | RESTORE (原数据) |
| 移动 clip | MOVE(new_pos) | MOVE(old_pos) |
| 修改字幕 | UPDATE_SUBTITLE(new_text) | UPDATE_SUBTITLE(old_text) |

Agent approve 后 commit 的操作不可本地 undo (使用 timeline version restore)。

### 栈上限

MAX_UNDO = 50, 超出时从底部丢弃最旧条目。pushUndo 时自动清空 redoStack (新操作打断重做链)。
