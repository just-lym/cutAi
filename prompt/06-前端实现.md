## API 客户端 (api/client.ts)
统一 fetch 封装 + 类型定义:
```typescript
const BASE = '/api'

async function request<T>(path: string, options?: RequestInit): Promise<T> {
  const res = await fetch(`${BASE}${path}`, {
    headers: { 'Content-Type': 'application/json' },
    ...options,
  });
  if (!res.ok) {
    const err = await res.json().catch(() => ({ detail: res.statusText }))
    throw new Error(err.detail || res.statusText)
  }
  return res.json()
}

export const api = {
  projects: {
    list: () => request<Project[]>('/projects'),
    create: (data) => request<Project>('/projects', { method: 'POST', body: JSON.stringify(data) }),
    get: (id) => request<Project>(`/projects/${id}`),
  },
  assets: {
    list: (projectId) => request<Asset[]>(`/projects/${projectId}/assets`),
    upload: async (projectId, file: File) => {
      const fd = new FormData(); fd.append('file', file)
      return await fetch(`${BASE}/projects/${projectId}/assets/upload`, { method: 'POST', body: fd }).json()
    },
  },
  timeline: {
  get: (projectId) => request(`/projects/${projectId}/timeline`),
  },
  subtitles: {
  update: (projectId, cueId, data) => request(`/projects/${projectId}/subtitles/${cueId}`, { method: 'PUT', body: JSON.stringify(data) }),
  remove: (projectId, cueId) => request(`/projects/${projectId}/subtitles/${cueId}`, { method: 'DELETE' }),
  },
  agent: {
  stream: (projectId, content, handlers) => streamAgentMessage(projectId, content, handlers),
  approve: (planId, indices?) => request(`/agent/runs/${planId}/approve`, { method: 'POST', body: JSON.stringify({ indices ?? {} }) }),
  },
  render: {
  preview: (projectId) => request(`/projects/${projectId}/previews`, { method: 'POST', body: '{}' }),
  exports: (projectId) => request(`/projects/${projectId}/exports`, { method: 'POST', body: '{}' }),
  job: (jobId) => request(`/jobs/${jobId}`),
  },
  usage: { summary: () => request(`/usage/summary`) },
}
```

TypeScript 类型: Project, Asset, Timeline, SubtitleCueDTO, AgentSession, EditPlan, EditOperation, ApproveResponse, BrollPosition, BrollCandidate, Job, UsageSummary

## 核心组件

### AgentPanel
- 聊天界面：消息列表 + 输入框
- 快捷操作按钮：去静音 / 生成字幕 / 插入 B-roll / 调整音量
- 状态：发送中显示 spinner “Agent 思考中...”
- 每条 AI 回复显示费用 (¥x.xxx)

### 操作卡片审批 (OperationCard):
- 每个操作独立卡片：图标 + 类型标签 + 字段 + +/-/x 按钮
- OP_META 映射: DELETE_RANGE→X, SET_VOLUME→🔊, FADE_TH→📉, INSERT_BROLL→🎬 等
- 本地决策状态: Record<index, 'approved' | 'rejected'>
- 批量操作: “全部确认” / “全部拒绝”
- “提交决策” 按钮（所有操作决策后才可用）
- 卡片展开显示操作参数详情
- **Hover 联动**: 鼠标悬停卡片 -> setHighlightRange -> 时间轴蓝色半透明高亮
- 提交调用 api.agent.approve(planId, { approved_indices, rejected_indices })
### 流式响应 (useAgentStream):
- 发送消息走 SSE stream 端点
- 逐字渲染 partial 气泡（带闪烁光标 ▍）
- thinking 状态显示当前 Agent 名称 + spinner
- “停止生成” 按钮 (AbortController)
- 流完成后 partial -> 正式消息
### B-roll 候选卡片:
- 当有 INSERT_BROLL 操作时显示缩略图网格（2列）
- 点击选中显示绿色边框 + ✓

### ScriptView (脚本视图)
- 文本化时间轴面板，编辑文字 = 编辑视频
- Tab 切换：编辑器下面板“时间轴”/“脚本”两个 tab
- **CueBlock 子组件**：每个字幕 cue 一行，包含时间码 + speaker 标签 + contentEditable 文本
- **播放同步**：二重置 playheadMs -> currentCueId，自动滚动到当前 cue (3s 用户滚动暂停)
- **文本编辑**：contentEditable plaintext-only, 300ms debounce -> api.subtitles.update
- **选择联动**：点击选中 cue, Shift+Click 范围多选
- **删除功能**：Delete 键删除选中 cues -> 生成 DELETE_RANGE draftOperation
- **搜索过滤**：输入框过滤匹配文本的 cue
- **低置信度**：confidence < 0.7 显示黄色背景提示

### AssetPanel
- 拖拽上传区域 (onDragOver + onDrop -> api.assets.upload -> refetch)
- @dnd-kit 可排序素材列表
- 图标按类型：VIDEO 🎬, AUDIO 🎵, IMAGE 🖼️, SUBTITLE 📄

### 设计规则
- 面板分隔：1px `border-editor-border`，resize handle 用同色 hover:accent-blue
- 圆角层级：外框 rounded-xl，卡片 rounded-lg，内部元素 rounded-md
- 字体：系统字体栈（PingFang SC / Microsoft YaHei fallback），正文 text-sm，辅助 text-xs
- 过渡：transition + ease-out，hover 状态用 editor-hover
- 毛玻璃：`.glass` utility (backdrop-blur-12 + editor-surface/75% opacity)
- 投影：--shadow-card (subtle)，--shadow-elevated (模态/浮层)
